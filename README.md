Project Overview

Agentic Flow is a Generative AI-powered workflow and knowledge management platform that combines Retrieval-Augmented Generation (RAG), vector search, and Large Language Models (LLMs) to answer user questions based on custom knowledge documents.

The platform allows users to upload knowledge documents, store them in a vector database, retrieve relevant information using semantic search, and generate intelligent responses using an open-source LLM running locally through Ollama.

The project demonstrates full-stack development, AI integration, REST API design, vector databases, and modern frontend development.
